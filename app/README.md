# Source officielle de Files Gallery

Conserver ici `index.php`, téléchargé explicitement depuis une version épinglée.

```sh
curl -fsSLo app/index.php https://cdn.jsdelivr.net/npm/files.photo.gallery@0.15.3/index.php
sha256sum app/index.php
```

Noter la somme dans `VERSION`. Ne jamais utiliser une URL sans `@VERSION`.
